🧠 AI App Builder Prompt: SnapVault – Cloud Media Storage App
🏷️ Project Title

SnapVault – Cloud Media Storage App (Mobile & Web Responsive)

💡 Objective

Create a modern, minimal mobile-first web application that allows users to upload, store, organize, view, and download photos & videos.
SnapVault solves limited iPhone storage by letting users back up their media directly to the cloud.

🖌️ Visual Identity
Property	Value
Primary Color	#4A90E2 (Sky Blue)
Secondary Color	#F5F7FA (Soft White Background)
Accent Colors	Green #34D399, Red #EF4444, Text Gray #4B5563
Fonts	Poppins (headings), Inter (body)
Border Radius	1rem (rounded-2xl)
Shadows	Soft, diffuse (similar to iOS cards)
Transitions	150ms ease-in-out
Layout Grid	8pt spacing system
Design Mood	Airy, clean, cloud-inspired, iOS aesthetic
⚙️ Technology Stack

Frontend: React (with Vite) + Tailwind CSS
Routing: React Router
Backend: Node.js + Express + MongoDB (Mongoose)
Auth: JWT (email/password + optional Magic PIN)
Storage: Local /uploads directory (extendable to cloud)
File Uploads: Multer middleware
Search & Filters: Local filtering (media type, album, date)

🧩 Backend API Endpoints
Method	Endpoint	Description
POST	/api/auth/signup	Create new account
POST	/api/auth/login	Authenticate user
GET	/api/albums	Get user’s albums
POST	/api/albums	Create new album
GET	/api/albums/:id	Get album media
POST	/api/upload	Upload media file
DELETE	/api/media/:id	Delete file
GET	/api/media/:id/download	Download media file
🧠 Core Logic & Data Structures
Feature	Implementation
Authentication	JWT (stored in localStorage)
Password Security	bcrypt hashing
Upload Queue	File upload queue using async/await
Search	Binary search + filter by file name/date
Album Linking	HashMap (user → albums → media)
Lazy Loading	Intersection observer for infinite scroll
File Metadata	Stored in MongoDB (file name, type, date, size, albumId, userId)
🧭 User Flow Summary

Onboard → Login or Signup

Signup/Login → JWT saved locally

Dashboard → Create album or upload directly

Upload → Show progress, store metadata in DB

Album View → Browse, view, download, or delete files

Settings → Manage account, theme, and storage

Logout → Clear local storage and redirect home

Album Document

{
  _id: "album1",
  name: "Vacation 2025",
  userId: "user123",
  createdAt: Date.now()
}


Media Document

{
  _id: "file789",
  albumId: "album1",
  userId: "user123",
  filename: "IMG_2025.jpg",
  path: "/uploads/IMG_2025.jpg",
  type: "image/jpeg",
  size: "2.8MB"
}

🔄 Interactions

Upload → shows live progress bar (width updates with percentage).

Clicking an image/video → opens Media Viewer overlay.

Download button → triggers backend GET /media/:id/download.

Create Album → opens modal → adds new album card instantly (optimistic update).

Logout → clears JWT → redirects to /login.
